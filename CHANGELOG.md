# Changelog

Todas as mudanças relevantes do LBedu serão registradas neste arquivo. O projeto segue [Semantic Versioning](https://semver.org/).

## Não publicado

### Adicionado

- posicionamento do projeto como biblioteca de receitas open source de IA;
- padrão editorial e técnico para novas receitas;
- Código de Conduta, Política de Segurança e guia de Suporte;
- formulários de issue e template de Pull Request;
- roadmap público e preparação da release inicial.

### Alterado

- README orientado a resultados e ao inventário real do repositório;
- guia de contribuição com fluxo rápido, testes e checklist;
- referências de marca em documentação e exemplo Python.

## v0.1.0

Release inicial planejada. As notas serão finalizadas depois que a fundação de lançamento for revisada e incorporada à branch `main`.
