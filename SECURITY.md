# Política de Segurança

## Versões mantidas

O LBedu está em fase inicial. Somente o conteúdo mais recente da branch `main` recebe correções de segurança.

## Como relatar uma vulnerabilidade

Não abra uma issue pública para vulnerabilidades, credenciais expostas ou dados pessoais.

Envie um relato para [lb@lbedu.me](mailto:lb@lbedu.me) contendo, quando possível:

- componente ou arquivo afetado;
- impacto esperado;
- passos mínimos para reprodução;
- sugestão de correção;
- forma segura de contato.

Não inclua chaves reais, tokens ou dados de terceiros. Use valores fictícios ou remova informações sensíveis.

## O que esperar

A manutenção tentará confirmar o recebimento em até cinco dias úteis. Depois da triagem, informará se o problema foi aceito, se precisa de mais dados e qual será o próximo passo possível.

O projeto é educacional e mantido por uma equipe pequena. Prazos de correção dependem de gravidade, disponibilidade e capacidade de reprodução.

## Escopo

São considerados relevantes:

- execução insegura nos exemplos;
- exposição acidental de segredos;
- dependências ou configurações claramente vulneráveis;
- instruções que possam induzir uso perigoso;
- falhas no domínio ou na infraestrutura oficial do LBedu.

Vulnerabilidades de provedores externos devem ser relatadas diretamente aos respectivos responsáveis.
