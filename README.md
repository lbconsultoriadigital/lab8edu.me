# LAB8 Open Source Hub (`lbedu.me`)

> Hub aberto de engenharia de IA, automação e desenvolvimento de agentes inteligentes da **LAB8**.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)

Este repositório reúne recursos práticos, frameworks de agentes, servidores MCP (Model Context Protocol), templates de integração e materiais de estudo aplicados para acelerar desenvolvedores e criadores na era da Inteligência Artificial.

---

## Estrutura do Repositório

- **`/prompts`**: Biblioteca de system prompts, instruções de contexto e personas para tarefas especializadas de engenharia, análise e automação.
- **`/templates`**: Boilerplates de código prontos para iniciar projetos integrados com LLMs (Claude, OpenAI, DeepSeek e APIs locais).
- **`/mcp-servers`**: Exemplos práticos e utilitários para criar e integrar ferramentas via Model Context Protocol.
- **`/scripts`**: Utilitários de automação em Python e Node.js para fluxos de dados, chamadas de API e testes.
- **`/docs`**: Guias práticos, arquiteturas de referência e tutoriais passo a passo.

## Como Começar

### Pré-requisitos
- Node.js (>= 18.x) ou Python (>= 3.10)
- Git instalado

### Clonando o Repositório
```bash
git clone https://github.com/lbconsultoriadigital/lab8edu.me.git
cd lab8edu.me
```

## Como Contribuir

Contribuições da comunidade são muito bem-vindas! Se você deseja adicionar um novo template, prompt, tutorial ou corrigir um bug:

1. Faça um Fork do projeto.
2. Crie uma Branch para sua feature (`git checkout -b feature/minha-melhoria`).
3. Faça commit das suas alterações (`git commit -m 'feat: adiciona template de agente'`).
4. Faça push para a Branch (`git push origin feature/minha-melhoria`).
5. Abra um Pull Request.

Consulte o arquivo [CONTRIBUTING.md](CONTRIBUTING.md) para diretrizes detalhadas.
