# LBedu v0.1.0: fundação aberta

A primeira release do LBedu estabelece uma base educacional para receitas práticas de Inteligência Artificial em português.

## Destaques

- três pontos de entrada reproduzíveis no README;
- prompts bilíngues para engenharia de software e arquitetura de agentes;
- agente mínimo em Python com testes e execução controlada;
- quickstart Node.js para Claude com streaming;
- introdução bilíngue ao Model Context Protocol;
- padrão público para novas receitas;
- verificações automáticas de links, Python e Node.js;
- arquivos de comunidade, segurança e suporte.

## Comece aqui

1. [Prompt de Engenheiro de Software](../../prompts/software-engineer.md)
2. [Agente mínimo em Python](../../templates/python-agent-boilerplate/README.md)
3. [Claude com streaming em Node.js](../../templates/node-claude-quickstart/README.md)

## Limites conhecidos

- a coleção ainda é pequena;
- o material MCP ainda não inclui um servidor executável;
- o exemplo Node.js requer uma chave da Anthropic;
- os exemplos são educacionais e precisam de avaliação adicional antes de uso em produção.

## Participe

Teste uma receita, relate o resultado e escolha uma issue marcada como `good first issue`. Consulte [CONTRIBUTING.md](../../CONTRIBUTING.md) para o fluxo completo.

Estas notas são um rascunho e serão finalizadas quando a release for publicada.
