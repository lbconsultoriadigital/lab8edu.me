<a name="português"></a>
## Português

Seja bem-vindo ao **LBedu**. Escolha um resultado pequeno e verificável em vez de tentar ler o repositório inteiro.

### 1. Escolha um ponto de partida

- **Copie e adapte:** leia o [prompt de sistema para Engenharia de Software](../../prompts/software-engineer.md).
- **Execute localmente:** rode o [agente mínimo em Python](../../templates/python-agent-boilerplate/README.md).
- **Conecte uma API:** siga o [quickstart do Claude em Node.js](../../templates/node-claude-quickstart/README.md).
- **Entenda MCP:** estude a [visão geral do protocolo](../../mcp-servers/README.md). Servidores MCP executáveis ainda estão no roadmap.

### 2. Clone o repositório

```bash
git clone https://github.com/lbconsultoriadigital/lbedu.me.git
cd lbedu.me
```

### 3. Verifique o exemplo local

```bash
cd templates/python-agent-boilerplate
python main.py
python -m unittest
```

Uma execução correta mostra a demonstração do agente e finaliza os testes sem falhas.

### 4. Contribua com o resultado

Se uma instrução estiver confusa ou seu ambiente se comportar de outra forma, abra uma issue informando versão, passos e saída sem dados sensíveis. Leia [CONTRIBUTING.md](../../CONTRIBUTING.md) antes de enviar código.
