<a name="english"></a>
## English

Welcome to **LAB8 Open Source Hub**! This guide helps you navigate and use the resources in this repository efficiently.

### 1. Choose your track
- **Prompt Engineering**: Check the [`/prompts`](../../prompts) folder to discover tested system prompts and persona definitions.
- **Application Development**: Explore [`/templates`](../../templates) for ready-to-use code boilerplates.
- **Tooling & MCP**: Review [`/mcp-servers`](../../mcp-servers) to build custom extensions and tool integrations for LLMs.

### 2. Local Setup
```bash
git clone https://github.com/lbconsultoriadigital/lbedu.me.git
cd lbedu.me
```
