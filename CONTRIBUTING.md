# Guia de Contribuição - LAB8 Hub

Agradecemos imensamente pelo seu interesse em contribuir para o **LAB8 Open Source Hub** (`lbedu.me`)!

Este documento estabelece as diretrizes para garantir que o processo de colaboração seja transparente, inclusivo e eficiente.

---

## O que você pode contribuir?

1. **Prompts e Agentes**: Novos prompts estruturados, personas e frameworks de instrução.
2. **Templates de Código**: Boilerplates práticos para conectar modelos de linguagem e automações.
3. **Servidores MCP**: Ferramentas e integrações utilizando o Model Context Protocol.
4. **Tutoriais e Guias**: Documentação clara e prática sobre arquitetura e desenvolvimento com IA.
5. **Correção de Bugs e Melhorias**: Otimizações de código e ajustes na documentação.

---

## Fluxo de Trabalho (Git Workflow)

1. **Fork do Repositório**:
   Crie uma cópia do repositório na sua conta do GitHub clicando no botão *Fork*.

2. **Clone Local**:
   ```bash
   git clone https://github.com/SEU-USUARIO/lbedu.me.git
   cd lbedu.me
   ```

3. **Criação de Branch**:
   Crie uma branch descritiva para o que está desenvolvendo:
   ```bash
   git checkout -b feat/novo-template-agente
   # ou
   git checkout -b fix/ajuste-script-automacao
   ```

4. **Padrão de Commits**:
   Utilizamos a convenção do *Conventional Commits*:
   - `feat:` para novas funcionalidades, prompts ou templates.
   - `fix:` para correções de bugs.
   - `docs:` para melhorias em documentação.
   - `refactor:` para refatorações sem mudança de comportamento.

5. **Abertura de Pull Request (PR)**:
   - Faça o push da sua branch para o seu fork.
   - Abra um Pull Request detalhando as alterações e o motivo da contribuição.
